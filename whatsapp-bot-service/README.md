# Al-Mawaid WhatsApp Bot (Simple QR Scan Setup)

A hassle-free WhatsApp Chatbot for Al-Mawaid that works **without Meta Business verification or Facebook Developer accounts**.

---

## 🚀 How to Run

Run this single command from your project root:

```bash
npm run bot:whatsapp
```

---

## 📱 How to Connect:
1. When you start the command, a **QR Code** will appear right in your terminal.
2. Open **WhatsApp** on your phone (either personal or WhatsApp Business).
3. Go to **Settings** (or 3 dots on Android) ➔ **Linked Devices** ➔ **Link a Device**.
4. Point your camera and **scan the QR Code**.
5. Done! The bot will now automatically respond to all member messages 24/7.

---

## 💬 Supported Commands:
- `MENU` / `TODAY` — Today's thali menu
- `TOMORROW` — Tomorrow's menu
- `SURVEY` — Weekly survey info / `APPLY ALL`
- `STATUS` — View saved weekly meal survey responses
- `FEEDBACK` — 1–5 star rating + meal comments
- `STOP` / `RESUME` — Thali pause/resume request
- `DUES` — Monthly dues and payment details
- `QUERY` — Submit support questions to admin
- `WHOAMI` — View linked thali profile
- `UNLINK` — Unlink WhatsApp number
